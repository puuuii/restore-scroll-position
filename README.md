# Restore Scroll Position (Chrome 拡張機能)

Web ページ・ローカルファイルの PDF をスクロールして離れ、再度開いたときに **最後にいた位置から自動で再開** できるようにする Chrome 拡張機能です。

## 機能

| 対象 | 挙動 |
| --- | --- |
| Web ページ (http/https/file の HTML) | コンテンツスクリプトがスクロール位置(px)を `chrome.storage.local` に保存し、新規ロード時に復元します |
| ローカルファイルの PDF (`file://*.pdf`) | `.pdf` への表示を検知して**拡張機能同梱の pdf.js ビューア**に切り替え、ページ番号 + ページ内オフセットで位置を記憶します(縮尺も保存) |

- バック/フォワードでの復元はブラウザ標準の履歴復元(history.scrollRestoration)に任せます。本拡張は「新規で開いたとき」の復元のみ行います。
- 記憶は LRU で最大 300 件まで保持されます。

## インストール方法(開発者モード)

1. Chrome を起動し、`chrome://extensions` を開く
2. 「開発者モード」を有効化
3. 「アンロードされた拡張機能を読み込む」でこのフォルダ(`restore-scroll-position`)を選択

## ローカル PDF を使用する場合の注意

ローカルファイルにアクセスするには、拡張機能の詳細画面で **「ファイル システムへのアクセス: すべてのファイルにアクセスする」** を許可してください(初回は再読み込みが必要になる場合があります)。

## 使い方

- 何もする必要はありません。PDF / Web ページを閲覧してスクロール → タブを閉じる → 再度開くだけで復元されます
- ビューア上のツールバーで拡大縮小できます。「幅」ボタンは横幅に合わせる表示に戻します

## 構成

```
manifest.json            MV3 マニフェスト
background.js            PDF(.pdf URL)を検知してビューアへリダイレクト
content.js               Web ページのスクロール位置保存/復元
lib/scroll-memory.js     chrome.storage.local 上の記憶(LRU 管理)を共用するヘルパー
viewer/viewer.html       自前 PDF ビューア
viewer/viewer.js         pdf.js (v4.8.69, 同梱) による描画と位置の保存/復元
vendor/pdf.mjs           pdf.js ライブラリ (pdfjs-dist 4.8.69)
vendor/pdf.worker.min.mjs pdf.js ワーカー
```

## 設計上の注意 / 制約

- **Web 上の PDF(http/https)は対象外**です。ローカルファイル(`file://`)の PDF のみサポートします。
- **Chrome 内蔵 PDF ビューアはクロースオリジン**のため、コンテンツスクリプトからスクロール位置を読み取れません。そのため PDF は自前ビューアで表示する方式を採用しています(既定ビューアの挙動・印刷ボタン等は使えません)。
- PDF の検出は URL の拡張子 `.pdf` に依存します。URL が `.pdf` にならない PDF(リダイレクトクエリのみの etc.)は対象外です。
- PDF の保存キーは URL です。ローカルファイルが**移動・改名された場合**、記憶は引き継がれません(同一パスなら継続して有効)。
- Web ページの復元はハッシュ無しの URL をキーとします(アンカー移動のみで記憶は更新されません)。

## 削除方法 / リセット

`chrome://extensions` で本拡張機能を削除すると、保存された位置データも残ります(消去したければ storage.local の `scrollPositions` キーを拡張機能のサービスワーカーコンソール等から削除可能)。「すべて消去」UI は未実装です。
